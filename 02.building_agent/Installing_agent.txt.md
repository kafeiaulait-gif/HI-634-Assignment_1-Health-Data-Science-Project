 ### How do I install Google Antigravity?  Is it an agent I need to install on my machine, like Claude Code?

Google Antigravity is a standalone desktop application rather than a command-line terminal agent like Claude Code.

Installing the standalone Google Antigravity desktop app on Windows is straightforward. It is fully compatible with Windows 10 (64-bit) and Windows 11.

---

## Step-by-Step Installation Guide


_Step 1: Download the Desktop Application_

1. Open your browser and navigate to the official Google Antigravity Download Page.

    https://antigravity.google/download/

2. Select the version that matches your computer's operating system:

    Download the Windows Installer

    * Windows 11/10: Download the x64 installer executable.

3. Click the "Download for x64" button to download the setup executable (a file usually named anti.exe or antigravity.exe, which is roughly 137 MB–158 MB).

---

_Step 2: Install the App and Run the Installer_

  On Windows: Double-click the .exe file and follow the onscreen setup wizard prompts.

      1. Once the download finishes, navigate to your Downloads folder and double-click the executable file.

      2. If Windows SmartScreen displays a warning about an unverified app, click "More Info" and then "Run anyway".

      3. On the setup window, click the toggle to accept the license terms and conditions, then click Next.

      4. Follow the setup wizard prompts, leaving the default settings and file paths as they are.

      5. Select the checkbox to "Create a desktop icon" if you want easy access, then click Install.

      6. Click Finish to close the setup wizard and launch the app automatically.

---

_Step 3: Launch and Authenticate_

      1. Open the app from your Applications menu or Start menu.

      2. Click "Continue with Google" to initiate the browser authentication flow.

      3. Log in with your personal Gmail credentials. This will automatically pair the app with your free-tier public preview access limits.

      4. Follow the brief initial onboarding wizard to pick your layout theme (like dark mode) and complete the configuration.
	  
	  5. Create a new "Project" folder and drop your patient dataset (e.g., a .csv or .xlsx file) directly into it.
	  
	  6. Prompt the agent in plain English: "Look at this patient dataset. Write a Python script to check for missing values, calculate the averages for each demographic, and plot a distribution of the patient outcomes. Run the script and show me the results."
	  
	  7. The agent will spin up the secure sandbox, write the code, execute it, handle any debugging automatically, and present you with the completed analysis.

<br>

    (Note: If you already have a preferred coding environment like VS Code or PyCharm and don't want a standalone app, you can alternately open your editor's extension marketplace, search for the official "Google Antigravity" extension, and install it as a plugin interface instead).
