
## What type of data files are in this dataset: 

https://archive.ics.uci.edu/dataset/45/heart+disease? 


### .CSV, .JSON, ??? 

* Which files actually have the data for the study?

---

* The UCI Heart Disease dataset uses .data files (which are plain-text, comma-separated files similar to raw .csv formatting but without column headers). It does not natively provide .json files.

* The specific files that contain the raw data for the study correspond to the four clinical databases involved:

	1.  cleveland.data: Contains the dataset from the Cleveland Clinic Foundation (this is the most famous and widely used "processed" subset in machine learning experiments).
	
	2.  hungarian.data: Contains data from the Hungarian Institute of Cardiology in Budapest.
	
	3.  switzerland.data: Contains data from University Hospital, Zurich, Switzerland.
	
	4.  long-beach-va.data: Contains data from the V.A. Medical Center, Long Beach, CA.
	
	5.  new.data: A combined or alternative raw format file containing additional records.
